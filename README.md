# gym log

Put these files in a folder on a free host (GitHub Pages, Netlify, Cloudflare Pages).
The files contain no personal data. Your logs live only on your phone.

## GitHub Pages
1. New repository with a random name (e.g. gl-7k2q9x), set to Public (free Pages needs it).
2. Upload every file in this folder (index.html at the top level, not inside a subfolder).
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Open https://YOURNAME.github.io/REPO/ in Safari on your iPhone.
5. Share > Add to Home Screen.

## Load your data
Open the home screen app, go to Backup, paste the text from gym-log-my-data.txt, tap "Load pasted backup".
Do this inside the installed app. The home screen app has separate storage from Safari.
